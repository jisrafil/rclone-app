Privacy policy

Joni's File Sync. Last updated October 5, 2026.

Who uses this app

This app is used only by its owner, on the owner's own computer, with the owner's own Google and Microsoft accounts. It is not offered to anyone else.

What it accesses

With the owner's permission, the app reads, creates, updates and deletes files in the owner's Google Drive so that chosen folders match the owner's Microsoft OneDrive.

What happens to your data

  • Files move directly between the owner's Google Drive and the owner's OneDrive.
  • No data is collected, stored on any server, sold, or shared with anyone.
  • Sign-in tokens are saved only in rclone's settings file on the owner's computer.
  • There is no advertising, tracking, or analytics.

Google API data

This app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from the Google Account page under Security, then Third-party apps and services.
